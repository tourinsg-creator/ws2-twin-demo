# Wafer geometry fleet twin — demo

Interactive simulation of several double-sided wafer geometry tools in a 300 mm bay:
load ports, robot, aligner and measurement chamber per tool; overhead transport and stocker;
dispatching, alarms, PMs, monitor wafers and tool matching.

Open: https://tourinsg-creator.github.io/ws2-twin-demo/

All dimensions, timings and measurement values are generic placeholders. Single self-contained
HTML file, no external scripts or fonts, so it also runs offline.
